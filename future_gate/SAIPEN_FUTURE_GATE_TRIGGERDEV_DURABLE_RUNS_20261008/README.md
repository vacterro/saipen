# SAIPEN Future Gate — Durable Autonomous Runs

This archive is a long-horizon design reference inspired by durable workflow/orchestration ideas visible in Trigger.dev.

It is intentionally not an implementation handoff for the current SAIPEN state. Treat it as a shelf document for future mutation after the current protocol/runtime foundation is stable.

Primary concept:

> A SAIPEN `/goal` should become a durable logical Run that survives model changes, provider changes, process death, host restarts, account changes, and compatible runtime upgrades.

Files:

- `FUTURE_GATE_DURABLE_AUTONOMOUS_RUNS.md` — proposed master Future Gate / roadmap.
- `REFERENCE_TRIGGERDEV_IDEAS.md` — source-derived ideas and how they map to SAIPEN.
- `MUTATION_VECTORS.md` — optional future directions that become possible once the foundation exists.

Priority order inside the roadmap is architectural, not a command to interrupt current Work.
