## What the patch does

It renames the existing checkpoint body to `_maintenance_checkpoint_unserialized`
and wraps `maintenance_checkpoint` in a bounded cross-process
`.saipen/locks/gc-maintenance.lock` acquisition using the existing
`FileWriterLock` and `writer_lock_timeout`, never nesting the project writer
lock. A timeout is recorded as durable maintenance debt (`GC_MAINTENANCE_FAILED`)
instead of being silently dropped. The diff is 48 added lines and one renamed
function; no behavior outside the checkpoint wrapper changes.
