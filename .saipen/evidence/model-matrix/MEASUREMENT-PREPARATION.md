# T-1464 measurement preparation

Preparation during the T-1316 frozen family; no live field trial, implementation
or acceptance claim is made here. SRC-106 sections 12-14 own the nine shapes.

The matrix must distinguish an unavailable host/provider from a completed run
whose product or protocol acceptance failed. Unknown metrics remain null; an
unreadable transcript never means zero tool calls, violations or escapes.
Configured model inventory does not establish live availability. A slower
completed run can retain the same quality; model names cannot change acceptance.

Reuse the real disposable Git-project binding and external task carrier from
`t1363_field_polygon`; use `worker.supervise` to own bounded incarnations and
replacement. The subject project must be outside the main worktree and its
binding must name that fixture. Capture the installed runtime generation and
host-native events, canonical carriers before/after, real product tests and
neighbor tests. Preserve each attempt, including refusal and infrastructure
failure. No model/provider identity belongs in the fixture's canonical ledgers.

Representative product: an integer arithmetic helper and a second importing
module, with independent deterministic regression and neighbor checks. Simple
repair and multi-file repair have distinct defects; regression repair contains
the reproducing test; misleading-hypothesis pressure contradicts the real test.
Active-Work and replacement shapes start from real journaled Work/phase and a
checkpoint, never from an invented model transcript. Replacement changes the
incarnation while preserving Source, Work, acceptance and execution epoch.
The blocked shape withholds an external contract: correct defer has no product
mutation and no fabricated PASS, and its evidence identifies the missing fact.

Use one shape definition, prompt and acceptance hash across every model. Record
QUALITY and EFFICIENCY in separate tables and structured files. Successful field
measurement can contain observed quality failures; it cannot claim parity from
them. A host boundary preventing live measurement stays an explicit external
blocker, rather than a synthetic positive run or a model-quality failure.
