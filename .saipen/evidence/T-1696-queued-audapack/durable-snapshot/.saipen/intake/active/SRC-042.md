G. STRICT ARCHIVE CLASSIFICATION
============================================================

The current helper isAudapackProjectArchiveName() is intentionally broad enough for existing AUTO ZIP/drop sanitation.

Do NOT use that broad heuristic alone as authority for automatic Send.

SAIHANDOFF auto-send requires stronger classification.

Classify an incoming file/drop as:

PROJECT_ARCHIVE
OTHER_ZIP
NORMAL_FILE
UNKNOWN

PROJECT_ARCHIVE requires:

- exactly one ZIP candidate;
- project identity derivable from the canonical archive naming rules;
- exactly one enabled registered AUDAPACK project matches that identity;
- no second different project archive is present;
- the active conversation does not contradict the resolved project identity.

Fail closed on ambiguity.

Do not auto-send merely because:

- filename contains "AUDAPACK";
- filename ends in a timestamp-looking suffix;
- filename is simply a ZIP;
- runtime projectName happens to contain a similar substring.
