=====================================================================
PRODUCT TARGET
=====================================================================

Create a very fast way to capture useful audits, roadmaps, repair instructions
and implementation handoffs from ChatGPT or clipboard into AUDAPACK.

Main workflow:

    ChatGPT response
        -> click IA
        -> Bridge durably saves capture
        -> project classified/suggested
        -> item appears in AUDAPACK INAUDIT Inbox

Later:

    open AUDAPACK
        -> see accumulated audits
        -> inspect project suggestion
        -> Assign
        -> PROJECT\audit\N.md
        -> GG / CC

Critical principle:

    CAPTURE FIRST
    CLASSIFY SECOND
    EXECUTE THIRD

Never lose content because project identity is uncertain.

=====================================================================

        PROJECT\audit\1.md

    OUTAUDIT -> results
    CAPTURE -> Inbox

3. CAPTURE WRITE MUST BE ATOMIC
=====================================================================

Browser success must mean:

    CONTENT IS DURABLY SAVED.

Not:

    HTTP request happened.

Persistence sequence:

    validate capture
    -> write body temp
    -> flush
    -> atomic replace

32. CLEAN CHAT WORKER AND IA CAPTURE ARE SEPARATE
=====================================================================

Important architectural distinction:

Browser audit worker scheduling requires:

    CLEAN conversation.

IA capture does NOT.

A useful audit may be captured from:

    an old long conversation
    an occupied conversation
    a finished conversation

Therefore:

    OCCUPIED worker != audit eligible

but:

    OCCUPIED page may still expose IA Capture buttons.

Do not accidentally reuse clean_for_audit as a capture eligibility requirement.

This distinction is important.
