CONFESSION IS NOT ENFORCEMENT.

A model recognizing after the fact that it violated STYLE does not count as
recovery, learning, or mitigation.

If the same response class can violate the same compactness contract again in a
fresh turn, the defect remains OPEN.

"Self-check before sending" must not be the only enforcement boundary.

For normal operational outputs, the model must not control the final response
shape freely.

Prefer:

    canonical machine facts
    -> typed response class
    -> bounded canonical renderer
    -> validation
    -> delivery

over:

    model-authored prose
    -> model self-review

The regression suite must include repeated-turn testing:

    turn 1:
        model attempts oversized response
        -> blocked/compressed

    turn 2:
        fresh response, same semantic pressure
        -> blocked/compressed again

    turn 3:
        large evidence set
        -> still compact

No credit for:

    "the model apologized"
    "the model correctly explained the rule"
    "the next sample happened to be short"

Acceptance requires the invalid response to become mechanically unreachable
where the host capability allows it.
