# Smart VAC Cleaner

[English](README.md) · [Русский](README.ru.md) · [Eesti](README.et.md) · [Дед](README.ded.md)

![Интерфейс Smart VAC Cleaner](assets/screenshot.png)

Портативный, безопасный, современный очиститель мусора для Windows. GUI + CLI + Планировщик задач.

Безопасен по умолчанию: dry-run, пока не указано `--delete`. Все корни
портативных приложений всегда числятся в конфиге; чистятся только те, что
реально существуют на этой машине, и только известные мусорные паттерны
внутри них. Отсутствующие диски молча пропускаются, никогда не дают ошибок.

## Что чистится

| Слой | Что | Где |
|---|---|---|
| Система | Temp, дампы падений, миниатюры Проводника, кэш обновлений Windows, кэш DNS, корзина, 100+ пользовательских кэшей приложений (браузеры, кэши Node/uv/pip, семейство VS Code, Eagle, OBS, Discord...) | `%TEMP%`, `%LOCALAPPDATA%`, `%APPDATA%` |
| Deep C: Junk | Остатки апдейтеров, `*.exe.tmp`, Viber QmlWebCache, резервные копии Яндекс.Диска, логи ODIS, `app.asar.bak` и подобное | `%LOCALAPPDATA%`, `%TEMP%` |
| Портативные корни | Известные мусорные паттерны внутри настроенных корней | `portable_roots` в конфиге |
| Пользовательские правила | Свои пути + glob-паттерны | `custom_rules` в конфиге |

## Безопасность (защита в глубину)

- **Dry-run физически read-only** — кнопка «Очистить» в GUI удаляет по-настоящему (с диалогом подтверждения), CLI требует `--delete` явно; dry-run только планирует, никогда не мутирует (никаких unlink/chmod/rmdir, никаких DNS flush, остановки сервисов, вызовов корзины)
- **Чёрный список**: `C:\`, `C:\Windows`, `USERPROFILE`, Program Files, собственная папка скрипта — это **пользовательские** корни (portable/custom), они отклоняются: ни один пользовательский корень не может быть защищённым путём или его потомком, даже если конфиг это требует. Проверенные внутренние системные цели (System Temp, кэши AppData, …) — не пользовательские корни: у них собственная явная область и собственный корень SafetyGuard
- **Без жёстко прописанных портативных корней**: свежий конфиг по умолчанию имеет `portable_roots: []`
- **Мин. глубина пути**: мелкие пути (менее 5 компонентов) отклоняются
- **Проверка запущенных процессов**: приложение, которое использует цель, пропускается (по-своему списку процессов); если таблицу процессов нельзя получить, цели, чувствительные к приложениям, тоже пропускаются (fail closed); снимок обновляется перед каждой деструктивной группой приложений
- **Покрытие владельцев**: каждая AppData-цель имеет проверенного владельца процесса или явно помечена как process-agnostic (общие кэши пакетов/компиляторов/драйверов) — нет неявного исключения `owner=None`
- **Симлинки / junctions / reparse-точки отклоняются**; сегменты `..` канонизируются, итоговый путь ограничивается корнем цели и перепроверяется — `..`, выводящий за пределы корня, отклоняется
- **Never-delete имена**: `login data`, `bookmarks`, `cookies`, `history`, `trusted_vault.pb` и другие — нумерованные (`Cookies (2)`) и составные журнальные (`Cookies (2)-wal`) варианты сводятся к защищённому базовому имени
- **Исключения**: `exclude_patterns` / `exclude_paths` в конфиге применяются к каждому удалению (portable, system, custom, deep sweep)
- **Резервные файлы**: общие артефакты `.bak` никогда не удаляются автоматически
- Каждое удаление проходит через `SafetyGuard` своего корня; каждый узел под удаляемой папкой валидируется, поэтому защищённые/исключённые поддеревья выживают; счётчики продвигаются только после подтверждённого удаления; ошибки считаются, никогда не фатальны
- GUI-воркер-нити никогда не трогают Tk; закрытие во время чистки отменяет и ждёт воркера перед выходом

## Требования

- Windows 10/11
- Python 3.10+

## Установка

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Как пакет (добавляет команду `vac-cleaner`):

```bat
pip install .
vac-cleaner --status
```

Нет Python? Возьмите `SmartVACCleaner.exe` на вкладке
[Releases](https://github.com/vacterro/SMART-VAC-CLEANER/releases) —
полностью портативный, конфиг и логи живут рядом с exe. Релизы
автоматически создаются из помеченных тегов через workflow `build-exe`;
если у версии есть тег, но нет страницы Release — workflow ещё не
завершился (или упал).

## Сборка exe самостоятельно

```bat
powershell -ExecutionPolicy Bypass -File build_exe.ps1
```

Результат: `dist\SmartVACCleaner.exe` (PyInstaller onefile). На каждый тег
`v*` CI собирает и загружает exe как артефакт автоматически.

## GUI

```bat
python _SMART_VAC_CLEANER.py
```

Семь кнопок: **Очистить** (реальное удаление — сначала спрашивает
подтверждение), **Стоп**, **Предпросмотр** (физически read-only dry-run,
показывает, что будет удалено), **Установить задачу автоочистки**,
**Запуск в фоне** (запускает отдельную скрытую полную очистку в фоне),
**Исключения** (правка списков никогда-не-удалять: шаблоны и пути),
**Системные цели** (включение рискованных целей — Корзина, кэш DNS,
кэш Windows Update; выбор сохраняется в конфиге). Прогресс-бары по
категориям, полное окно лога; каждый запуск также попадает в
`logs\clean_*.log`.

## CLI

CLI **по умолчанию dry-run** — только отчёт о том, что будет удалено.
Добавьте `--delete` для реального удаления. `--dry-run` принудительно
включает предпросмотр даже при `--delete`.

| Флаг | Эффект |
|---|---|
| `--cli` | Принудительный консольный режим |
| `--portable` / `--system` / `--custom` | Выбор слоёв очистки (по умолчанию dry-run) |
| `--all` | Все слои сразу с **безопасными** дефолтами системных целей (Корзина / DNS / Windows Update остаются выключены) |
| `--delete` | **Реальное удаление** (без него — только предпросмотр) |
| `--dry-run` | Принудительный предпросмотр даже с `--delete` |
| `--status` | Показать объём мусора по целям; ничего не удаляется |
| `--analyze-caches` | Поиск папок кэша в AppData размером > 5 МБ |
| `--sys-targets` | Список системных целей через запятую (`System Temp`, `User Temp`, `Recycle Bin`, ...); неизвестные имена дают ошибку |
| `--exclude` | Доп. паттерны исключений через запятую (`--exclude "*.db,*.tmp"`) |
| `--hidden` | Скрыть окно консоли (для Планировщика) |
| `--install-task` | Установить ежедневную тихую полную очистку |
| `--time ЧЧ:ММ` | Время запуска задачи (по умолчанию `09:00`) |

Примеры:

```bat
REM предпросмотр всего
python _SMART_VAC_CLEANER.py --cli --all

REM реальное удаление всего
python _SMART_VAC_CLEANER.py --cli --all --delete

REM предпросмотр, затем удаление; --dry-run всегда побеждает
python _SMART_VAC_CLEANER.py --cli --all --delete --dry-run
```

Сколько мусора накопилось:

```bat
python _SMART_VAC_CLEANER.py --status
```

### Автоочистка (Планировщик задач)

```bat
python _SMART_VAC_CLEANER.py --install-task --time 09:00
```

Устанавливает задачу `SmartVACCleaner` (макс. права, скрытое окно). Удаление:

```bat
schtasks /Delete /TN SmartVACCleaner /F
```

## Конфигурация

`cleaner_config.json` автоматически создаётся рядом со скриптом (или exe)
при первом запуске, с дефолтами. Все пути в нём канонизируются при загрузке:
стиль слешей, хвостовые разделители и сегменты `..` нормализуются, дубли
схлопываются, защищённые пути (`C:\`, Windows, Program Files, профиль,
собственная папка программы) и вложенные корни отклоняются с предупреждением.
Пример:

```json
{
  "portable_roots": ["D:\\Portable"],
  "custom_rules": [{"path": "D:\\Apps\\TestApp", "pattern": "*.log"}],
  "exclude_patterns": ["*.db"],
  "exclude_paths": ["C:\\Users\\me\\AppData\\Local\\Important"],
  "auto_clean_interval_hours": 0,
  "lang": "en"
}
```

- `portable_roots`: папки, чьи известные мусорные подпапки выметаются (например, `Cache`, `Temp`, `Logs`, нумерованные резервные копии). Всё, что не подходит под мусорные паттерны, не трогается.
- `custom_rules`: `path` (папка) + `pattern` (glob, `*` = всё содержимое).
- `exclude_patterns` / `exclude_paths`: дополнительные запретные списки.
- `lang`: язык интерфейса — `en` (по умолчанию), `ru`, `et`, `ded`. Встроенные `strings/*.json` лежат рядом со скриптом (или вшиты в exe); добавьте свой `<lang>.json`, чтобы добавить язык.

- Установка задачи Планировщика требует прав администратора (`/rl HIGHEST`).
- Портативные корни на несистемных дисках чистятся и без админа (схема VAC).
- Проект не аффилирован ни с одним вендором; все пути — известные кэш/лог-каталоги приложений, которые они пересоздают.
