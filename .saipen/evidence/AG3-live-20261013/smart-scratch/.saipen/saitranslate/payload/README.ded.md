# Smart VAC Cleaner

[English](README.md) · [Русский](README.ru.md) · [Eesti](README.et.md) · [Дед](README.ded.md)

![Smart VAC Cleaner GUI](assets/screenshot.png)

Нормальная чистилка без мусора, портативная. GUI, CLI, планировщик.

По дефолту — dry-run, пока не впишешь `--delete`. Чекает только те диски, что реально есть, сносит только известную срань. Нет диска — молча идёт дальше, без истерик.

## Че чистим

| Слой | Что именно | Где |
|---|---|---|
| Система | Темпы, дампы, кэш апдейтов винды, DNS, корзина, кэши прог (больше 100 таргетов: браузеры, нода/pip, VS Code, OBS, Дискорд...) | `%TEMP%`, `%LOCALAPPDATA%`, `%APPDATA%` |
| Глубокая срань (C:) | Ошмётки апдейтеров, `*.exe.tmp`, кэш вайбера, бекапы яндекса, логи ODIS | `%LOCALAPPDATA%`, `%TEMP%` |
| Портабельные | Известный мусор внутри твоих папок с портабельным софтом | `portable_roots` в конфиге |
| Свои правила | Твои личные папки + маски файлов | `custom_rules` в конфиге |

## Защита (чтоб не отстрелить ногу)

- **Dry-run физически read-only** — в GUI жмёшь "Снести нахер" (спросит подтверждение), в консоли нужен флаг `--delete`; dry-run только планирует, никогда не мутирует (никаких unlink/chmod/rmdir, DNS flush, остановки сервисов, вызовов корзины)
- **Запретки**: `C:\`, `C:\Windows`, `USERPROFILE`, Program Files, папка самого скрипта — это **юзерские** корни (portable/custom), они шлются лесом: ни один юзерский корень не может быть запретным путём или его потомком, даже если конфиг это просит. Внутренние проверенные системные цели (System Temp, кэши AppData, …) — не юзерские корни: у них своя явная область и свой корень SafetyGuard
- **Без захардкоженных портативных корней**: свежий конфиг по дефолту `portable_roots: []`
- **Минимальная глубина**: короткие пути (меньше 5 уровней) шлём лесом
- **Живые процессы**: если прога сейчас открыта — её кэш не трогаем (по своим спискам процессов); если таблицу процессов нельзя достать — цели, чувствительные к прогам, тоже не трогаем (fail closed); снимок обновляется перед каждой деструктивной группой
- **Покрытие владельцев**: каждая AppData-цель имеет проверенного владельца процесса или явно process-agnostic (общие кэши пакетов/компиляторов/драйверов) — никаких скрытых `owner=None`
- **Симлинки / junctions / reparse-точки шлются лесом**; `..` канонизируется, итоговый путь сидит внутри своего корня и перепроверяется — наружу не выпустим
- **Никогда не сносим**: `login data`, `bookmarks`, `cookies`, `history`, `trusted_vault.pb` и прочее — нумерованные (`Cookies (2)`) и составные журнальные (`Cookies (2)-wal`) варианты механически сводятся к защищённой базе
- **Исключения**: `exclude_patterns` / `exclude_paths` в конфиге действуют на каждое удаление (portable, system, custom, deep sweep)
- **Бэкапы**: общие `.bak` откатные файлы сами не трогаем
- Всё идёт через `SafetyGuard`; каждый узел под удаляемой папкой валидируется, так что защищённые/исключённые поддеревья выживают; счётчики двигаются только после подтверждённого удаления; ошибки считаем, но не падаем
- GUI-воркер-потоки никогда не трогают Tk; закрытие во время чистки отменяет и ждёт воркера перед выходом

## Че надо

- Windows 10/11
- Python 3.10+

## Установка

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Или пакетом (появится команда `vac-cleaner`):

```bat
pip install .
vac-cleaner --status
```

Нет питона? Качай `SmartVACCleaner.exe` из [Releases](https://github.com/vacterro/SMART-VAC-CLEANER/releases) — портативная сборка, конфиг и логи будут рядом. Release'ы создаются автоматически из помеченных тегов через workflow `build-exe`; если версия с тегом, а Release нет — workflow ещё не закончил (или упал).

## Собрать exe самому

```bat
powershell -ExecutionPolicy Bypass -File build_exe.ps1
```

Выплюнет `dist\SmartVACCleaner.exe` (PyInstaller). На каждом теге `v*` CI сама собирает exe-шник.

## GUI

```bat
python _SMART_VAC_CLEANER.py
```

Семь кнопок: **Снести нахер** (снесёт реально — сначала спросит), **Тормози**, **Глянь сперва** (физически read-only, покажет, что снесёт), **Вшить автозапуск**, **В фон** (запустит тихую зачистку без окон), **Не трогать** (твои исключения) и **Системные цели** (включить рискованное — Корзину, кэш DNS, кэш Windows Update; выбор помнится в конфиге). Прогресс-бары, логи. Все запуски пишутся в `logs\clean_*.log`.

## Консоль (CLI)

В консоли **dry-run по дефолту** — просто покажет, сколько говна нашлось.
Добавь `--delete`, если реально хочешь снести. `--dry-run` перебивает `--delete` и заставляет просто показать.

| Флаг | Чё делает |
|---|---|
| `--cli` | Железно консольный режим |
| `--portable` / `--system` / `--custom` | Выбор слоёв (по дефолту просто покажет) |
| `--all` | Все слои разом с **безопасными** дефолтами системных целей (Корзина / DNS / Windows Update остаются выключены) |
| `--delete` | **УДАЛЯЕТ** (без этого просто покажет) |
| `--dry-run` | Перебивает delete, тупо превью |
| `--status` | Показывает сколько мусора лежит; ничего не удаляет |
| `--analyze-caches` | Ищет кэши в AppData тяжелее 5 МБ |
| `--sys-targets` | Переопределить системные таргеты через запятую (`System Temp`, `User Temp`, `Recycle Bin`, ...); неизвестные имена — ошибка |
| `--exclude` | Доп исключения через запятую (`--exclude "*.db,*.tmp"`) |
| `--hidden` | Прячет консоль (для планировщика) |
| `--install-task` | Вшивает тихую чистку в планировщик |
| `--time HH:MM` | Во сколько запускать (дефолт `09:00`) |

Примеры:

```bat
REM показать всё
python _SMART_VAC_CLEANER.py --cli --all

REM снести всё
python _SMART_VAC_CLEANER.py --cli --all --delete

REM сунул оба флага - отработает как превью
python _SMART_VAC_CLEANER.py --cli --all --delete --dry-run
```

Глянуть че там скопилось:

```bat
python _SMART_VAC_CLEANER.py --status
```

### Авто-чистка (Планировщик)

```bat
python _SMART_VAC_CLEANER.py --install-task --time 09:00
```

Вшивает задачу `SmartVACCleaner` (высшие права, скрыто). Снести задачу:

```bat
schtasks /Delete /TN SmartVACCleaner /F
```

## Конфиг

`cleaner_config.json` сам создастся рядом со скриптом (или exe) при первом запуске. Все пути нормализуются: слеши, `..`, защитные блеклисты (C:\, Windows, профиль) — всё проверяется. Пример:

```json
{
  "portable_roots": ["D:\\Portable"],
  "custom_rules": [{"path": "D:\\Apps\\TestApp", "pattern": "*.log"}],
  "exclude_patterns": ["*.db"],
  "exclude_paths": ["C:\\Users\\me\\AppData\\Local\\Important"],
  "auto_clean_interval_hours": 0,
  "lang": "en"
}
```

- `portable_roots`: папки, внутри которых ищем мусорные шаблоны (Cache, Temp, Logs). Остальное не трогаем.
- `custom_rules`: `path` (папка) + `pattern` (маска, `*` = всё).
- `exclude_patterns` / `exclude_paths`: что не трогать.
- `lang`: язык — `en` (дефолт), `ru`, `et`, `ded`. Файлики `strings/*.json` лежат рядом (или вшиты в exe). Кинь свой `<lang>.json`, чтоб добавить.
