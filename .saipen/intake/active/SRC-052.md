======================================================================
FUTURE REQUIREMENT: `/goal cc all`
======================================================================

User wants:

    /goal cc all

to become an INTERNAL FORCED EXECUTION DIRECTIVE.

It must NOT be represented as an ordinary project goal such as:

    saipen goal "cc all"

because `cc all` is not user Work.

It is scheduler/execution policy over already-existing Work.

Conceptual internal representation:

    execution_directive:
        kind: CONTINUE_ALL
        forced: true
        origin: operator
        scope: current_project

UI may continue exposing the convenient alias:

    /goal cc all

but internally it must be classified separately from normal user goals.

======================================================================
CORE SEMANTIC
======================================================================

`cc all` means:

    continue selecting and executing the next legal actionable Work
    without requiring the operator to repeatedly issue `cc`

Conceptual loop:

    CONTINUE_ALL
        -> select highest legal actionable Work
        -> execute
        -> checkpoint
        -> select next legal actionable Work
        -> ...

until a REAL terminal/intervention condition occurs.

Examples of legitimate stop conditions:

    PROJECT_DONE
    CONVERGENCE_COMPLETE
    NO_ACTIONABLE_WORK
    WAIT_OPERATOR
    BLOCKED_EXTERNAL
    RECOVERY_REQUIRED
    SAFETY_REFUSAL
    FOREIGN_LIVE_OWNER
    other canonical non-bypassable blocker

Critical invariant:

    FORCED SCHEDULING != FORCED AUTHORITY

`cc all` MAY force continued scheduling.

It MUST NOT:

    bypass guards
    answer operator decisions
    steal another seat
    bypass ownership
    cross repository authority
    convert BLOCKED into DONE
    auto-attest evidence
    suppress SAI-DEFECT / WAIT
    loop through repeated Improve cycles merely because the board is idle

======================================================================
NO FAKE WORK
======================================================================

`/goal cc all` must NOT create:

    SRC-###
    Work ticket
    fake project goal
    coverage obligation

It is execution intent, not project intent.

Keep the semantic separation:

    USER WORK INTENT
        -> Source / Work / BOARD

    OPERATOR EXECUTION DIRECTIVE
        -> scheduler policy

Preferred internal naming:

    execution_directive

rather than overloading ordinary `goal`.

======================================================================
EXPECTED UX

    origin: operator

advance to the next legal Work.
