## 2. Findings

### AD-001 · CRITICAL · Необоснованная retry-eligibility для неопределённого результата

- **Класс:** CONFIRMED DRIFT в логике классификации; реальный duplicate side effect пока НЕ доказан.
- **Актор / время / ID:** `zcode-agent`, 19:24:55–19:25:36 UTC, M301/M309/M314; `call_694240` (`Edit`, `L49353`), `call_531674` (`Edit`, `L50456`), и другие edits до `L51622`; тесты M338 `call_812971` (`L54948`), M416 `call_801844` (`L67285`).
- **Evidence:** `isContinueReasonRecoveryEligible` возвращает `true` для `guard.recognizedContinueSaipenTimeout`, `...Failed`, `...UnreadableAnswer` (`L49388–L49423`); `v4-bridge.ts` ставит `recoveryEligibility` из этого helper (`L50488–L50517`); `TRANSIENT_REASON_CODES` и `isQueuePauseRecoverable` разрешают восстановление для этих трёх исходов (`L48945–L48946`, `L53824–L53972` и `L54993–L55013`). Сам агент заявил, что transient транспортные сбои автоматически восстанавливаются (`L60886–L60916`, `L68551–L68576`).
- **Rule / owner:** прямо нарушает пользовательские пункты **4, 5H и 8** (`L1840–L2050`): неизвестное admission не должно автоматически replay; требуется durable reconciliation, гарантированная non-admission и доказательство idempotency. Дополнительно `CORE.md` (copy-time `L71910–L71960`, авторитет эффекта и сохранение данных), точный отдельный rule ID на запрет retry **не предъявлен**.
- **Prosecution:** timeout, crash или нечитаемый JSON — **не доказательство non-execution**; дочерний процесс может успеть выполнить действие до потери ACK. Булево поле «recoverable» нельзя без дополнительных условий использовать в автоматическом повторе оригинального `cc`. Само изменение ускоряет опасный путь, который handoff запрещает.
- **Defense:** callback может использовать `recoveryEligibility` лишь для снятия системной паузы, не для повторной отправки. Старые дедупликационные тесты существуют; transcript не демонстрирует фактическую двойную side effect. Нельзя утверждать, что дубликат уже случился.
- **Вывод / confidence:** **HIGH** — доказано небезопасное *разрешение класса*, фактический повтор зависит от остального worker flow. **Корень:** смешение transient *transport* с доказанным *transaction non-admission*.
- **Task:** разделить `may_unpause_ui`, `may_retry_operation` и `requires_reconcile`. Timeout/unreadable/crash после spawn → `EXECUTION_UNKNOWN` до сверки неизменного command ID и durable receipt. Добавить real-worker tests: timeout после side effect, lost ACK, restart, duplicate-preservation. Не допускать автоматического повторного вызова без reconciliation.
