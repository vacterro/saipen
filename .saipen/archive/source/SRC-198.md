FINDING F-01: RECOVERY AUTHORIZATION BYPASS

SEVERITY: P0

Python and Node runtimes.

gate to:

object into decide().

lease gate.

compatibility adjustment.

The observed direct Python test returned PASS after this
change.

The executor subsequently identified the mistake and
planned a universal lease gate.

The provided session does not prove that the correction
was implemented.
