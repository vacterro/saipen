INDEPENDENTLY REPRODUCED ROOT CAUSE

The provider sorts core-unit evidence filenames in reverse
lexicographical order and selects the first record.

The filenames begin with hash-like prefixes.

Therefore filename order is not execution-time order.

Against a supplied real SAIPEN evidence corpus, the provider
selected an old PASS containing fewer tests even though newer
full-family FAIL evidence existed.

The result was:

satisfaction_status = SATISFIED
completeness_status = COMPLETE

This is incorrect evidence selection.

The affected persistent goal can prematurely stop generating
repair Work.
