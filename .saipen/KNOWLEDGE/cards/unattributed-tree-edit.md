# Adjudicate an unattributed working-tree edit, never ship it

An unexplained edit to a shipped document or validator is adjudicated on its own ticket and adopted or reverted with the reason recorded, because riding along in another release makes an unreviewed rule or weakened check indistinguishable from adjudicated law.

Why:
The same shape recurred three times: a carve-out weakening append-only, a fast-path check quietly loosened from a gap test to a monotonicity test, and shipped protocol prose rewritten by an unidentified writer. All were defensible edits arriving without authority, and while they sat uncommitted the injector reported a dirty source and every consumer install stayed behind.
